# Aoi explains: Claude Code on your phone

An animated explainer page hosted by Aoi, the pixel-art host from `aoi-kit/`.

- **Open it:** `aoi/index.html`. One self-contained file (Aoi's sprites are embedded as base64), no API keys, no audio, works offline and on a phone.
- **Controls:** scenes auto-advance. Tap anywhere to finish the line or skip to the next scene. Top-right buttons pause/play and restart. Space and → work on a keyboard. Add `#4` to the URL to start at scene 4.
- **Scenes:** hello → two kinds of sessions → cloud sessions need a repo → keep other repos private → remote control without GitHub → recap checklist → outro.
- **Look:** the `stand-blue-navy` palette. Aoi is drawn on a canvas with image smoothing off, with mouth flaps while her subtitle types, random blinks, a gentle bob, and a new pose or expression each scene. Following the kit's "show, do not restate" rule, the card shows a mock screen or diagram, never her sentence.
